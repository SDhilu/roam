# Roam ✈️

A travel-focused web application built with React, designed to provide a modern and engaging web experience for exploring travel-related content.

## Overview

Roam is a frontend development project focused on building a responsive travel website with an emphasis on user experience, interface design, and interactive web elements.

## Technology Stack

- **React 19** — UI development
- **Vite** — Development server and build tooling
- **React Router** — Client-side navigation
- **GSAP** — Animations and interactive effects

## Getting Started

Clone the repository:

```bash
git clone https://github.com/SDhilu/roam.git
cd roam
```

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the local URL provided by Vite in your browser.
